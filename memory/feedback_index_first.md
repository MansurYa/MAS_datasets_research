**Правило:** При любом изменении файловой структуры — создании, удалении, перемещении файла — обновить все индексные файлы.

**Почему:** Мансур работает с Claude Code в разных сессиях. Без актуальных индексов каждый новый AI или я в новой сессии не видит актуальной карты. Без обновления MEMORY_INDEX — записи стареют и врут.

**Как применять:**
- Создал файл в `work/specs/` или `work/reports/` → добавить строку в `memory/MEMORY_INDEX.md`
- Удалил файл → закомментировать или удалить строку из MEMORY_INDEX
- Переместил файл → обновить путь в MEMORY_INDEX
- Завершил TZ → обновить `memory/TZ_STATUS.md`
- Создал памятку по учебнику → обновить STATS_BOOK_INDEX.md
- Обновил памятку по учебнику → обновить её дату и содержание
- Обновил TZ_STATUS → проверить, что MEMORY_INDEX.md ссылается на актуальный TZ_STATUS
