Всегда использовать виртуальное окружение `.venv` для запуска Python скриптов в этом проекте.

**Why:** Система macOS защищена (externally-managed-environment), прямая установка пакетов через pip заблокирована. Виртуальное окружение обходит это ограничение.

**How to apply:**
1. Создать виртуальное окружение (если ещё не создано): `python3 -m venv .venv`
2. Активировать перед запуском скриптов: `source .venv/bin/activate`
3. Установить нужные библиотеки через `pip install` или `pip install -r requirements.txt`
4. Запускать Python скрипты через активированное окружение

Конкретные зависимости указаны в `requirements.txt` или в спецификации TZ-задачи.
