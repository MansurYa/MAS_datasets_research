## Часть C. Полный пересчёт статистики

Для **трёх источников** (TRAIL, AgentRx, Who&When Hand-Crafted) и **keyword search** (без изменений):

### C1. P(траектория) + P(сообщение) + Wilson CI

Для каждой пары (error_id × source):
- `p_trajectory` = n_trajectories_with_error / n_trajectories_total
- `p_message` = n_occurrences / total_steps
- Wilson 95% CI для обоих

### C2. Описательная статистика позиций

Для ошибок с n ≥ 5:
- Абсолютная позиция: mean, median, std, min, max, p25, p75, p90, p95
- Нормализованная: step / trajectory_length → [0, 1]

### C3. Гистограммы

Для ошибок с n ≥ 20: гистограммы абсолютных и нормализованных позиций.
PNG в `data/plots/`.

### C4. Подгонка распределений

Для ошибок с n ≥ 20: подогнать 8 распределений (Exponential, Weibull, LogNormal, Beta, Uniform, Pareto, Gamma, Lomax). MLE + KS-тест.

Для n ≥ 3000: KS информативен. Для n < 100: предупреждение о низкой мощности.
