## Задачи

### Задача 1. Унификация таксономии AgentRx

Загрузить оба аннотированных файла (`magentic_one.jsonl`, `tau_retail.jsonl`). Объединить все `failure_category` в единый список, нормализовав написание (привести к нижнему регистру, убрать лишние пробелы, объединить очевидные дубли — например "Instruction/Plan Adherence Failure" и "Instruction Adherence Failure" → одна категория).

Результат: словарь `{оригинальное_название: унифицированное_название}`.

### Задача 2. Keyword-based классификация Who&When

Для каждой записи в Who&When применить следующие правила к полю `mistake_reason` (в порядке приоритета — первое совпавшее правило побеждает):

| Категория | Ключевые слова/паттерны |
|---|---|
| `hallucination` | hallucinate, fabricat, made up, assumes the existence, placeholder |
| `code_error` | code is incorrect, code is wrong, python code, incorrect code, code provided, bug, syntax |
| `tool_web_failure` | failed to access, 404, retrieve, websurfer, filesurfer, could not access, not found, url |
| `resource_abuse` | exhaustion of the step limits, step limit, too many steps, repeatedly |
| `orchestration_failure` | orchestrator, replan, wrong direction, should not decide, should instruct |
| `factual_error` | factual error, incorrect information, incorrect assumption, incorrect fact, wrong answer |
| `misinterpretation` | misinterpret, misidentif, incorrect interpretation, wrong interpretation |
| `unclassified` | (всё остальное) |

Применять к тексту в нижнем регистре.

### Задача 3. Базовая статистика

Для каждой категории ошибок посчитать по каждому датасету:

- `n_failures` — число вхождений ошибки
- `n_trajectories_with_error` — число траекторий, содержащих хотя бы одно вхождение
- `n_trajectories_total` — общее число траекторий в датасете
- `p_trajectory` = `n_trajectories_with_error / n_trajectories_total`
- `ci_lower`, `ci_upper` — Wilson 95% CI для `p_trajectory`

Формула Wilson CI:
```python
from scipy.stats import norm
z = norm.ppf(0.975)  # 1.96
n = n_trajectories_total
p = p_trajectory
center = (p + z**2/(2*n)) / (1 + z**2/n)
margin = z * (p*(1-p)/n + z**2/(4*n**2))**0.5 / (1 + z**2/n)
ci_lower = center - margin
ci_upper = center + margin
```

Если `n_trajectories_with_error < 20` — добавить флаг `insufficient_data = True`.

### Задача 4. Распределение по шагам

Для каждой категории собрать список позиций ошибок:
- AgentRx: поле `step_number` из failures
- Who&When: поле `mistake_step`

Для каждой категории вычислить: `mean`, `median`, `std`, `min`, `max`, `p25`, `p75`, `n`.
