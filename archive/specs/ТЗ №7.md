- Абсолютные: min=2, max=594, mean=19.4, median=14, p90=36
- Нормализованные (step / trajectory_length): min=0.003, max=0.993, mean=0.40, median=0.37, p90=0.77

### B2. Дополнительно: смесь распределений

**Mixture of 2 Shifted Exponentials:**
```python
F(x) = π * Exp_shift(x; loc1, scale1) + (1-π) * Exp_shift(x; loc2, scale2)
```
где π — вес первой компоненты. Оценивать EM-алгоритмом. 4 параметра: π, loc1, scale1, scale2.

Обоснование: данные могут иметь две группы — ранние ошибки (плохой URL сразу) и поздние (rate limiting после многих попыток). Если Hartigan's dip test (часть C) отвергнет бимодальность — Mixture не запускать.

## Часть C. Сравнение моделей

### C1. Информационные критерии

Для каждого кандидата:

```
AIC = 2k - 2·log_lik
BIC = k·ln(n) - 2·log_lik
AICc = AIC + 2k(k+1)/(n-k-1)  (скорректированный для малых n — но n>>k, можно без)
```

где k — число параметров, n = 26,379.

Таблица:

| Распределение | k | log_lik | AIC | BIC | ΔAIC |
|---|---|---|---|---|---|
| Beta | 4 | ... | ... | ... | 0 (лучшее) |
| ShiftedExp | 2 | ... | ... | ... | ... |

**ΔAIC = AIC_current - AIC_best.** Если ΔAIC > 10 — модель значимо хуже лучшей.

### C2. Ошибка квантилей

Вычислить эмпирические квантили в 9 точках: p10, p20, p30, p40, p50, p60, p70, p80, p90.

Для каждого кандидата вычислить:

```
RMSE_quantiles = sqrt(mean((Q_emp(p_i) - Q_theor(p_i))^2))
MaxAE_quantiles = max(|Q_emp(p_i) - Q_theor(p_i)|)
```

Для абсолютных позиций — квантили в шагах. Для нормализованных — в единицах [0,1].

Также вычислить MAPE по квантилям: `mean(|Q_emp - Q_theor| / Q_emp) * 100`.

### C3. Сравнение с эталоном: эмпирическое CDF

Эмпирическое CDF — это **идеальная** подгонка (непараметрическая). Для каждого кандидата вычислить:

```
KS_to_empirical = max|F_emp(x) - F_candidate(x)|
```

Это покажет "насколько кандидат далёк от идеала". Если лучший параметрический даёт KS < 0.02 — он практически неотличим от эмпирики.

## Часть E. Проверка на бимодальность

### E1. Hartigan's dip test

```python
from diptest import dip_test  # pip install diptest
dip, p_value = dip_test(data)
```

Если p < 0.05 → данные бимодальны → запустить Mixture of 2 Exponentials (часть B2).

Если p ≥ 0.05 → бимодальность не подтверждена → Mixture не нужен.

### E2. Визуальная проверка

KDE (ядерная оценка плотности) с узкой полосой — для визуального обнаружения мод.

```python
from scipy.stats import gaussian_kde
kde = gaussian_kde(data, bw_method=0.05)
x_grid = np.linspace(data.min(), data.max(), 500)
plt.plot(x_grid, kde(x_grid))
```
