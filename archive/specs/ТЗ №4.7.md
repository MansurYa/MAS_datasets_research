Седьмое задание в серии. В ТЗ №4.6 все стандартные распределения (Exponential, Weibull, LogNormal, Beta) были отвергнуты KS-тестом для nebius-категорий (n=26k–34k). Причина — тяжёлый хвост: median=14, max=594 для tool_web_failure. Нужно попробовать распределения специально для тяжёлых хвостов.

## Задача 1. Дополнительные распределения

Для всех надёжных пар из ТЗ №4.6 добавить к подгонке:

- **Pareto** (`scipy.stats.pareto`) — специально для тяжёлых хвостов вида P(X>x) ~ x^(-α)
- **Gamma** (`scipy.stats.gamma`) — обобщение экспоненциального, гибче по форме
- **Lomax** (`scipy.stats.lomax`) — сдвинутое Pareto, удобно для данных начинающихся с нуля

MLE через `scipy.stats.*.fit()`. KS-тест через `scipy.stats.kstest`.

Для nebius (n>>3000): KS-тест информативен, отвержение H0 реально. Для ITBench/terminalbench (n<300): низкая мощность, результаты иллюстративны.
