## 3. Анализ контекстной длины

Данные о длине контекста доступны для Who&When (total_chars из history), но ни одна категория не имеет n≥20 ошибок с привязкой к question_ID для надёжного анализа.

## 4. Ограничения

1. **TRAIL исключён** — синтетический источник, параметры не подтверждены экспериментально.
2. **n<<3000 для всех ошибок** — нельзя делать уверенных выводов о виде распределения.
3. **Keyword matching для Who&When** — покрытие ~54% (85/184 записей не классифицировано).
4. **KS-тест** — параметры оценены по тем же данным, что и тестируются (сложная гипотеза, §2.2.4 Буре), p-value завышено.
5. **P(message)** — использует фактическое число шагов в траекториях, но не учитывает вариативность длины контекста.
