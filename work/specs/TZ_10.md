# TZ_10. Спецификация: Code Execution Errors в nebius

**Дата:** 2026-06-05
**Статус:** Завершено

---

## 1. Контекст

Исследование runtime errors (code execution) в nebius/SWE-agent-trajectories.
Это **другой тип** от invalid_invocation (pre-execution):

| Тип | Описание | Пример |
|-----|----------|--------|
| `invalid_invocation` (E1/E2) | Pre-execution validation | SyntaxError, undefined name в edit tool |
| `code_execution` | Runtime execution | TypeError, AttributeError при запуске reproduce.py |

### Источник данных

`datasets/nebius-SWE-agent-trajectories/` — 80 036 траекторий.

---

## 2. Определения

### 2.1. Code Execution Error

Python runtime exception, возникающий при выполнении agent-written скрипта.

**Критерии:**
1. Python exception type (TypeError, AttributeError, ImportError, etc.)
2. Traceback указывает на agent-written script
3. НЕ является edit validation (E1/E2)
4. НЕ является network error (HTTPError, Connection refused)

### 2.2. Agent-Written Scripts

Файлы, созданные агентом:
- `/reproduce.py` — основной скрипт для воспроизведения issue
- `/test_*.py` — unit tests
- `/run_*.py` — runner scripts
- `/script.py`, `/debug.py`, `/verify.py` — вспомогательные

### 2.3. Issue Description Errors (FP)

Python errors, скопированные из текста issue description.
Отличаются от TP тем, что traceback указывает на `/opt/conda/envs/...` (системные пакеты), а не на agent-written scripts.

## 3. Архитектура парсера

### Структура файлов

```
work/MAS_errors/parsers/nebius/code_execution/
  __init__.py
  parser.py
  code_execution/
    errors.parquet         # TP: agent script errors (full)
    errors_dedup.parquet   # TP: agent script errors (deduped)
    errors_issue.parquet   # FP: issue description errors
    stats.json
  tests/
    test_parser.py
```

### parser.py — ключевые функции

| Функция | Описание |
|---------|----------|
| `matches_agent_script()` | TP: Python error + agent script path |
| `matches_issue_description()` | FP: Python error без agent script |
| `parse_error_type()` | Извлечение типа и сообщения ошибки |
| `normalize_error_pattern()` | Нормализация для дедупликации |
| `is_edit_validation()` | Исключение E1/E2 |
| `is_network_error()` | Исключение network errors |

### Subtypes

| Subtype | Описание | Пример |
|---------|----------|--------|
| TypeError | Неверный тип | `TypeError: string indices must be integers` |
| AttributeError | Нет атрибута | `'NoneType' object has no attribute 'get'` |
| ImportError | Нет модуля/имени | `ImportError: cannot import name 'X'` |
| ModuleNotFoundError | Нет модуля | `No module named 'X'` |
| NameError | Не определена переменная | `NameError: name 'X' is not defined` |
| ValueError | Неверное значение | `ValueError: invalid literal` |
| KeyError | Нет ключа | `KeyError: 'missing'` |
| IndexError | Нет индекса | `IndexError: list index out of range` |
| Other | Другие | `RuntimeError`, `AssertionError`, etc. |

## 4. Выходные данные

### errors.parquet (TP)

| Поле | Описание |
|------|----------|
| traj_idx | Номер траектории (0-80035) |
| step_idx | Номер шага |
| chars_before_error | Контекст до ошибки (символы) |
| error_subtype | TypeError / AttributeError / etc. |
| error_text | Полный текст ошибки (truncated to 2000) |
| normalized_pattern | Нормализованный паттерн |
| exit_status | exit_status траектории |

| instance_id | Идентификатор instance |
| traj_total_chars | Всего символов в траектории |
| traj_total_steps | Всего шагов в траектории |
| target | target=True/False |
| occurrence_in_traj | Номер вхождения в траектории |
