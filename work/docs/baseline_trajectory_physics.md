# Baseline trajectory physics — nebius/SWE-agent-trajectories

Файл с фундаментальными инсайтами «на века». Только то, что мы прямо увидели в данных в TZ_3 (см. `work/reports/TZ_3_baseline_eda_report.md`). Никаких гипотез.

**Источник:** 80 036 траекторий, 12 шардов parquet, `datasets/nebius-SWE-agent-trajectories/`.

## Аксиомы

### A1. Бенчмарк убивает агента по **объёму контекста**, не по числу шагов

90% траекторий с `exit_group=limit_hit` лежат в узком диапазоне **85 603 — 129 584 символов** (q05–q95). После 100 000 символов вероятность завершить успехом падает с ~85% до ~3% (см. кросстаб §5.2 отчёта).

**Следствие для симулятора:** распределение момента ошибки нужно параметризовать по `n_chars`, а не по `step_idx`.

### A2. Жёсткой стенки на конкретном номере шага нет

Топ-20 наиболее частых `n_ai_steps` — гладкое монотонно убывающее распределение. Никакого пика на «50», «75» или «100». Лимит шагов в этом бенчмарке либо отсутствует, либо стоит выше типичных значений (max `n_ai_steps` = 408).

### A3. Состав популяции по исходу

| Группа | n | % |
|---|---:|---:|
| success (`submitted`) | 51 087 | 63.83% |
| limit_hit (контекст/формат/стоимость) | 24 707 | 30.87% |
| failed (`early_exit`, `submitted_no_patch`) | 4 242 | 5.30% |

Из всех `limit_hit` доминирует контекст (24 594 / 24 707 = 99.5%); формат и стоимость можно игнорировать.

### A4. Медианные длины траектории

| Метрика | success | limit_hit | failed |
|---|---:|---:|---:|
| `n_steps` (медиана) | 27 | 81 | 31 |
| `n_chars` (медиана) | 33 124 | 109 349 | 35 851 |

### A5. Минимальная длина траектории и её состав

- Минимум `n_steps` = 2 (system + один user или один ai).
- Минимум `n_chars` ≈ 8 343 — это система: `system_prompt` ~5 КБ + короткий issue + минимальный ответ.
- Шаг 0 всегда `role='system'`, `text=''`, `system_prompt≈5 КБ`. Дальше строго `user → ai → user → ai → ...`.

### A6. Попытки не независимы

3 591 уникальная задача × в среднем 22.3 попытки на задачу (медиана 16, max 125). Любой стат-тест должен это учитывать (groupby `instance_id`).

### A7. Длина считается в символах

Точный токенизатор модели агента нам недоступен. Все цифры выше — в символах исходного текста (включая system_prompt и текст всех шагов).

Эмпирическая оценка для перевода в токены (если понадобится): для английского ~1 токен ≈ 4 символа, то есть стенка ~100 000 символов ≈ ~25 000 токенов. Это **косвенная оценка**, не использовать в формальных расчётах.

### A8. submitted ≠ задача решена; реальный успех — target=True

Поле `target` (bool) — результат проверки патча тестами. Среди 51 087 траекторий с `exit_group=success`:

| target | n | % |
|---|---:|---:|
| True (патч прошёл тесты) | 12 672 | 24.8% |
| False (патч не прошёл) | 38 415 | 75.2% |

Медианные длины среди success по target:

| target | n_steps (медиана) | n_chars (медиана) |
|---|---:|---:|
| True | 24 | 29 395 |
| False | 27 | 34 713 |

Успешные (target=True) траектории короче — агент решает задачу быстрее. Для симулятора DA реальный критерий успеха — `target=True`, а не просто `submitted`.
