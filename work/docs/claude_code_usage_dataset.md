# Claude Code Usage Dataset — описание

**Датасет:** `datasets/claude_code_usage_kv_cache_loss.csv`
**Формат:** CSV (анонимизированный)
**Дата публикации:** 2026-05

---

## Обзор

Claude Code Usage — анонимизированный датасет API-логов Claude Code. Содержит запросы к Claude API через Code-клиент за период ~35 дней.

**Особенность:** Данные не имеют встроенного разделения на траектории. Сессии выделяются по временным перерывам (>30 минут).

---

## Структура данных

### Столбцы

| Столбец | Тип | Описание |
|---------|-----|----------|
| Time | datetime | Время запроса |
| Input Tokens | int | Число входных токенов |
| Output Tokens | int | Число выходных токенов |
| Cache Read Tokens | int | Токенов прочитано из cache |
| Cache Creation Tokens | int | Токенов записано в cache |

### Пример данных

```
Time,Input Tokens,Output Tokens,Cache Read Tokens,Cache Creation Tokens
2026-02-15 09:23:11,1234,567,890,234
2026-02-15 09:23:45,1456,678,1234,456
2026-02-15 10:15:22,2345,890,0,1234
...
```

## Определение сессий

Сессия — непрерывная последовательность запросов с интервалами < 30 минут.

```
Интервал > 30 минут → новая сессия
```

Каждый запрос имеет:
- `session_id` (0-85)
- `step_in_session` (номер шага, начиная с 0)

### Тёплые vs холодные сессии

**Тёплая сессия:** хотя бы один запрос имеет Cache Read Tokens > 0. Таких 68 из 86.

**Холодная сессия:** все запросы имеют Cache Read Tokens = 0. Таких 18 (849 запросов).

Холодные сессии не используют cache — для них анализ cache_loss не применим.

---

## KV Cache Loss в данных

### Определение события

KV cache loss регистрируется когда:
1. Интервал с предыдущего > 30 мин
2. `Cache Read Tokens = 0`
3. Предыдущий шаг в сессии имел `Cache Read Tokens > 100`

### Статистика (только тёплые сессии)

Найдено 23 события из 67 запросов после перерыва.

P(loss | after_gap) = 34.3%

## Использование для исследований

### Через study_runner

Парсер `work/MAS_errors/parsers/claude_code_usage/parser.py` автоматически:

## Ограничения

1. **Анонимизация:** Удалены идентифицирующие поля (user, project, repo)
2. **Один клиент:** Все запросы от Claude Code, не от других клиентов
3. **Отсутствие ground truth:** Мы не знаем истинных причин cache loss, только косвенные признаки
4. **Холодные сессии:** 18 сессий не используют cache — анализ cache_loss для них не применим
