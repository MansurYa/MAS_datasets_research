## Ключевое: почему стандартный KS недостаточен

> §2.2.4: «Статистика D*_n распределена иначе, чем D_n. Причина: из-за подбора параметра θ по выборке функции F_n(x) и F_0(x, θ̂) оказываются «ближе» друг к другу.»

**Вывод:** Если параметры распределения оценены по той же выборке (MLE) — стандартный KS некорректен. Нужна модифицированная статистика из §2.2.4.

## Формулы для TZ_4_9

**Модифицированный KS для нормальности (§2.2.4, Табл. 2.1):**
```
D̃*_n = D*_n × (√n − 0.01 + 0.85/√n)
Критическое значение (α=0.05): 0.895
```

**Модифицированный ω² для нормальности (§2.2.4, Табл. 2.1):**
```
ω̃²_n = ω²_n × (1 + 0.5/n)
Критическое значение (α=0.05): 0.126
```

## R-функции (§2.2.5)

```r
ks.test(x, "pnorm", mean=mu, sd=sigma)   # KS-тест
cvm.test(x)                               # Cramér-von Mises (пакет nortest)
ad.test(x)                                # Anderson-Darling (пакет nortest)
fitdistr(x, "exponential")               # MLE через MASS
AIC(fit); BIC(fit)                        # информационные критерии
bartlett.test(list(x1, x2))              # критерий Бартлетта
```
