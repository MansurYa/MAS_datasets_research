O'Fallon и соавторы (1980) в статье "Modified Kolmogorov-Smirnov test procedure with application to arbitrarily right-censored data" разработали модифицированную статистику, учитывающую дисперсию, вычисляемую по формуле Гринвуда, и доказали ее асимптотическую слабую сходимость к супремуму броуновского моста. Эта модификация позволяет корректно оценивать согласие параметрических моделей с цензурированными данными.Реализация в Python: Критические ограничения библиотеки lifelinesВ экосистеме Python доминирующим инструментом для анализа выживаемости является библиотека lifelines. Она предоставляет классы KaplanMeierFitter для визуализации функции выживания и CoxPHFitter для пропорционального регрессионного моделирования рисков. Для сравнения двух выборок с цензурированными данными lifelines предлагает функцию logrank_test (лог-ранговый критерий).Однако документация lifelines прямо указывает на фундаментальные ограничения лог-рангового критерия: он обладает максимальной мощностью только тогда, когда выполняется предположение о пропорциональности рисков (proportional hazards). Если функции выживания пересекаются (что часто бывает в инженерии при сравнении различных режимов износа), лог-ранговый критерий теряет мощность и выдает недостоверные оценки статистической значимости. При этом в архитектуре lifelines полностью отсутствуют реализации критериев на базе эмпирической функции распределения (Колмогорова-Смирнова, Крамера-фон Мизеса) для параметрической оценки согласия с учетом цензурирования. В релизе 1.11.0 библиотека scipy добавила объект CensoredData и функцию ecdf для вычисления распределений с цензурированием , однако функция проверки согласия goodness_of_fit не адаптирована для прямой работы с CensoredData по методологии Флеминга.Реализация в R: Пакет GofCensВ экосистеме R задача решается исчерпывающе с помощью пакета GofCens. Оценка параметров теоретического распределения выполняется через вызов функции fitdistcens из пакета fitdistrplus, использующей метод максимального правдоподобия с учетом функции вклада цензурированных наблюдений.Аргумент KScensНазначение и алгоритмическое поведениеtimesВектор временных отсчетов до наступления события или выбытия.censВектор статусов (1 — точное время отказа, 0 — цензурировано справа).distrСтрока, определяющая теоретическое распределение (например, "weibull", "lognormal").params0Список a priori известных параметров. Важным архитектурным нюансом является обработка связок (ties) — ситуаций, когда несколько событий происходят в один и тот же момент времени. Документация пакета предупреждает, что алгоритмические различия в определении эмпирической функции распределения $\hat{F}_n(t)$ при наличии связок могут приводить к флуктуациям статистики. Для надежной промышленной интеграции рекомендуется применять предварительный джиттеринг (добавление бесконечно малого шума к временным отсчетам) для искусственного разрушения связок.Вычислительный блок 5: Коррекция Майнсхаузена (Meinshausen correction) для высокоразмерных данныхТрадиционные методы статистического вывода и расчеты p-value были разработаны для сценариев, в которых размер выборки $n$ значительно превышает количество предикторов $p$. В современных задачах предиктивной аналитики, биоинформатики и мониторинга сенсорных сетей возникает ситуация $p \gg n$ (high-dimensional inference). Применение классических моделей в таких условиях приводит к сингулярности матриц ковариации и переобучению.Методология 2.0 использует подход многократного сэмплирования (Multi-sample splitting), теоретические основы которого были заложены в статье Nicolai Meinshausen, Lukas Meier, и Peter Bühlmann (2009) "P-values for high-dimensional regression". Одиночное разделение выборки предполагает использование первой половины данных ($I_1$) для отбора значимых переменных (variable selection) с помощью алгоритмов регуляризации (например, Lasso), а второй половины ($I_2$) — для классического статистического вывода над отобранным подмножеством $\hat{S}$. Однако, как математически доказали авторы, такой подход порождает "лотерею p-value" (p-value lottery) — итоговые оценки значимости катастрофически зависят от случайного генератора, разделившего выборку.Для устранения стохастической нестабильности Майнсхаузен и др. предложили проводить процедуру разделения $B$ раз (где $B$ велико). На каждой итерации $b$ для переменной $j$ вычисляется сырое p-value $P_j^{(b)}$. Затем эти значения корректируются с учетом множественного тестирования: $P_{corr,j}^{(b)} = \min(P_j^{(b)} \cdot |\hat{S}|, 1)$. Финальная агрегация использует квантильную функцию для вычисления доверительного интервала, скорректированного на логарифмический множитель $(1 - \log(\gamma_{min}))$, который является математической "платой" за поиск оптимальной границы квантили.Архитектура пакета hdi в RОфициальная и академически строгая реализация данного алгоритма представлена в R-пакете hdi (High-Dimensional Inference), разработанном самими авторами методологии. Ниже представлен пример промышленного интеграционного кода, демонстрирующего вызов модифицированного критерия Каплана-Майера и коррекции Майнсхаузена из Python.Pythonimport numpy as np

def evaluate_censored_ks_rpy2(times: np.ndarray, cens: np.ndarray, distr_name: str = "weibull") -> dict:
    """
    Интеграционный мост для вызова GofCens::KScens.
    Вычисляет модифицированную статистику Флеминга для цензурированных данных.
    """
    # Добавление микро-джиттеринга для устранения алгоритмических флуктуаций при наличии связок (ties)
    jitter = np.random.uniform(0, 1e-6, size=len(times))
    times_jittered = times + jitter
    
    # Конвертация массивов numpy в R-вектора
    r_times = ro.FloatVector(times_jittered)
    r_cens = ro.IntVector(cens)
    
    # Вызов KScens с boot=False для использования аналитической аппроксимации p-value
    # При использовании boot=True на больших выборках возникнет блокировка потока (GIL)
    with localconverter(ro.default_converter + pandas2ri.converter):
        result = gofcens.KScens(times=r_times, cens=r_cens, distr=distr_name, boot=False)
    
    # Извлечение результатов из возвращаемого списка R (S3 объекта KScens)
    ks_stat = result.rx2('A')
    p_value = result.rx2('p-value')
    
    return {'KS_statistic': ks_stat, 'p_value': p_value}

def compute_meinshausen_hdi(X: pd.DataFrame, y: pd.Series, B: int = 50) -> np.ndarray:
    """
    Интеграционный мост для вызова hdi::multi.split.
    Применяет метод Multi-sample splitting для расчета p-value в условиях p >> n.
    """
    # Передача объектов через контекстный менеджер для изоляции конверсии
    with localconverter(ro.default_converter + pandas2ri.converter):
        r_X = base.as_matrix(X)
        r_y = ro.FloatVector(y.values)
        
        # Вызов функции hdi.multi.split
        # Осторожно: вызов lasso.cv B раз требует значительной оперативной памяти
        result = hdi.multi_split(x=r_X, y=r_y, B=B)
        
        # Конвертация R-вектора p-value обратно в массив numpy
        adj_pvals = np.array(result.rx2('pval'))
        
    return adj_pvals

Для матриц, превышающих объемы кэша процессора, это приведет к деградации производительности. Кроме того, при возникновении фатальных ошибок внутри R-пакетов, интерпретатор R может завершиться с ошибкой сегментации (Segmentation Fault), что приведет к немедленному падению всего процесса Python, обходя блоки try-except. Экосистема Python (опирающаяся на BSD-лицензированные инструменты scipy и lifelines) превосходит R в задачах маршрутизации данных, векторизованных математических преобразованиях и построении пайплайнов.
