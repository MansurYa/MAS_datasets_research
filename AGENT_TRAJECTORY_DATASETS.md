# Датасеты агентных траекторий

Отобранная коллекция датасетов машинного обучения, содержащих реальные многошаговые траектории выполнения AI-агентов. Все включённые датасеты содержат подлинные взаимодействия со средой с сохранением полной хронологии: рассуждение → вызов инструмента → ответ среды.

**Применённые критерии исключения:** датасеты с изолированными парами состояние-действие (без порядка шагов), данные, полностью синтезированные моделью без реального выполнения в среде, а также бенчмарки и списки задач (не корпуса предварительно собранных траекторий).

---

## 1. `nebius/SWE-agent-trajectories`

**Домен задач:** Разработка ПО / Терминал

**Содержимое:** 80 036 полных сессий агентов, пытающихся исправить реальные баги из GitHub-репозиториев. Использован для обучения open-weight SE-агента, достигшего 40.6% на SWE-bench Verified.

**Статистика многошаговости:**
- Успешные траектории: в среднем **31.3 шага**, макс. **408 шагов**
- Неуспешные траектории: в среднем **58.4 шага**
- 13 389 успешных, 66 647 неуспешных

**Формат:** Parquet (12 шардов в `data/`)

**Схема:**
- `instance_id` — идентификатор задачи SWE-bench
- `model_name` — использованная базовая модель
- `target` — эталонный патч
- `trajectory` — список шагов (мысль, действие, наблюдение)
- `exit_status` — успех/неудача
- `generated_patch` — сгенерированный агентом фикс
- `eval_logs` — логи оценки

**Загрузка:**
```python
from datasets import load_dataset
ds = load_dataset("nebius/swe-agent-trajectories")
```

**Лицензия:** CC BY 4.0 (результаты требуют соблюдения Llama 3.1 License); лицензии SWE-bench extra встроены.

## 4. `ibm-research/ITBench-Trajectories`

**Домен задач:** SRE / Диагностика облачной инфраструктуры

**Содержимое:** 105 полных траекторий выполнения SRE-агентами (Site Reliability Engineering) инцидентов в реальных облачных средах. Включает пошаговое рассуждение, использование диагностических инструментов и анализ метрик.

**Структура:** Иерархическая по сценариям:
```
ReAct-Agent-Trajectories/<model>/<category>/Scenario-<N>/<attempt>/
  session.jsonl       — полный пошаговый лог сессии
  agent_output.json   — итоговый вывод агента
  judge_output.json   — оценка судьи
```

**Формат:** JSONL + JSON (поддиректории по сценариям)

**Схема:**
- `session.jsonl` — каждая строка = один шаг: timestamp, role (user/assistant/tool), content
- Шаги включают: рассуждение, вызовы инструментов (диагностические команды, запросы метрик), ответы среды

**Загрузка:**
```python
from datasets import load_dataset
ds = load_dataset("ibm-research/ITBench-Trajectories")
```

## 5. `Kevin355/Who_and_When`

**Домен задач:** Анализ отказов мультиагентных систем

**Содержимое:** 184 аннотированных случая отказов из реальных прогонов мультиагентных систем (например, Magentic-One). Предоставляет полные истории переписок для алгоритмической локализации критического шага отказа в длинных цепочках агент-агентных обменов.

**Суб-датасеты:**
- `Algorithm-Generated.parquet` — отказы, выявленные автоматическим анализом
- `Hand-Crafted.parquet` — аннотированные вручную случаи отказов
- `Who&When/` — индивидуальные JSON-файлы с детальной аннотацией каждого случая

**Формат:** Parquet + JSON

**Схема:** Полная история мультиагентных сообщений; аннотирована маркерами шагов отказа и указанием ответственного агента.

**Сценарий использования:** Исследование координационных отказов мультиагентных систем, локализация шага отказа и атрибуция в длинных цепочках переписок.

**Загрузка:**
```python
from datasets import load_dataset
ds = load_dataset("Kevin355/Who_and_When")
```

## 6. `microsoft/AgentRx`

**Домен задач:** Анализ отказов агентов в разных доменах

**Содержимое:** ~159 неуспешных траекторий агентов в нескольких доменах (взаимодействие с API, веб-серфинг, управление инцидентами). Датасет спроектирован для изучения **где и почему агенты ошибаются** — каждая траектория аннотирована на уровне шага: категория отказа, номер шага и виновный агент.

**Статистика многошаговости:** Переменная на траекторию; пошаговая аннотация позволяет детально локализовать отказ.

**Формат:** JSONL (4 файла)

| Файл | Записей | Схема |
|------|---------|-------|
| `magentic_dataset.jsonl` | 58 | `trajectory_id`, `instruction`, `steps` |
| `magentic_one.jsonl` | 44 | `trajectory_id`, `failure_summary`, `failures[]`, `root_cause` |
| `tau_retail_dataset.jsonl` | 28 | `trajectory_id`, `instruction`, `steps` (с подшагами) |
| `tau_retail.jsonl` | 29 | формат траектории |

**Детали схемы (magentic_one):**
- `failures[].step_number` — номер шага, на котором произошёл отказ
- `failures[].failure_category` — категория отказа
- `failures[].failed_agent` — агент, вызвавший отказ
- `failures[].step_reason` — текстовое объяснение отказа
- `root_cause_failure_id` — корневая причина в цепочке отказов

**Сценарий использования:** Локализация отказов на уровне шагов, атрибуция в мультиагентных системах, анализ ошибок в задачах с длинным горизонтом.

**Загрузка:**
```python
from datasets import load_dataset
ds = load_dataset("microsoft/AgentRx")
```

## 7. `iMeanAI/Mind2Web-Live`

**Домен задач:** Веб-навигация / GUI-агенты

**Содержимое:** 542 задачи веб-навигации с 4 550 детализированными шагами взаимодействия на уровне элементов. В отличие от большинства веб-датасетов, предоставляющих только скриншоты, этот набор фокусируется на динамической многошаговой оценке реальных взаимодействий с сайтами.

**Статистика многошаговости:** в среднем **5–9 последовательных переходов этап-состояние** на сессию

**Формат:** JSON (файлы train/test: `mind2web-live_train_*.json`, `mind2web-live_test_*.json`)

**Схема:** Записи веб-взаимодействий на уровне шагов: целевые элементы, действия, наблюдения и переходы состояния страницы.

**Загрузка:**
```python
from datasets import load_dataset
ds = load_dataset("iMeanAI/Mind2Web-Live")
```

## Исключённые датасеты

### `ernie-research/TARA` — СИНТЕТИЧЕСКИЙ, ИСКЛЮЧЁН

**Причина исключения:** Траекторные логи в TARA полностью сгенерированы моделью (синтетические) — ответы, оценки и следы вызовов инструментов были созданы языковыми моделями без реального выполнения в среде. Каждая запись представляет собой самодостаточную пару вопрос-ответ без реальных вызовов инструментов или обратной связи от среды.

**Предназначение:** Исследование tool-augmented reward modeling (ICLR 2024), не обучение на траекториях.

**Загрузка (не рекомендуется для исследований реального выполнения):**
```python
from datasets import load_dataset
ds = load_dataset("ernie-research/TARA", "calculator")  # любой конфиг
```
